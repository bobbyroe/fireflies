# Three.js Animation and Fireflies Effect

This repository showcases a real-time 3D scene built with Three.js. The project features animated fireflies and an imported FBX model with animation.

## Features

- **Animated Fireflies**: Dynamically orbiting fireflies with glow effects.
- **FBX Model Loading**: Imports and animates an FBX model using `FBXLoader`.

## Installation

Clone the repository:
   ```bash
   git clone https://github.com/bobbyroe/fireflies.git
   cd fireflies
   ```

### Scene Overview

- **Fireflies**: Each firefly orbits in a circular motion and emits a subtle glow.
- **FBX Model**: The scene includes an imported `.fbx` model with animations.

### Controls

- Use the mouse to rotate, zoom, and pan the camera.
- The scene automatically resizes when the browser window changes size.

## Key Dependencies

- [Three.js](https://threejs.org/): JavaScript 3D library for rendering the scene.
- `FBXLoader`: Loader for importing FBX files into the scene.
- `OrbitControls`: Enables interactive camera manipulation.
